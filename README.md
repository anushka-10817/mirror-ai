#  Mirror AI

### Your Personal Productivity Dashboard

Mirror AI is a Flask-based productivity project designed to help users organize their tasks, understand priorities, and keep track of deadlines through a simple dashboard.

##  Features

*  **Task Management:** Organize and manage tasks.
*  **Deadline Tracking:** Keep track of upcoming deadlines.
*  **Priority Insights:** Identify tasks that need attention.
*  **Interactive Dashboard:** Access productivity information through a web interface.

##  Tech Stack

* Python
* Flask
* HTML
* CSS
* JavaScript (if used in the interface)

##  Getting Started

### Prerequisites

* Python 3 installed
* Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/anushka-10817/mirror-ai.git
   ```

2. Navigate to the project directory:

   ```bash
   cd mirror-ai
   ```

3. Create and activate a virtual environment:

   **Windows PowerShell:**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. Install Flask:

   ```bash
   pip install flask
   ```

5. Start the application:

   ```bash
   python app.py
   ```

6. Open your browser and visit:

   http://127.0.0.1:5000
